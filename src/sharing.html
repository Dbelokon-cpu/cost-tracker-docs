Projects

Every cost project has an owner (its creator at first), a general access setting and an optional list of people. Open Settings → Sharing (owners only) to change it.

General accessMeaning
EveryoneAnyone using the app can open the project, view-only. This is the default for a new project.
RestrictedOnly the owner and the people you name can open it.

You can add people as Viewer or Editor, up to 50. Naming someone lifts them above the general setting: an Editor can change a restricted or an "everyone" project alike.

Adding a person

Under Add a person, type at least two letters of a name or email. The search is live and lists existing users of your Jira site. It does not send invitations or email, so someone new must first be invited to the Jira site (Jira settings → User management → Invite user). App accounts are not offered, only people.

Transferring ownership

The owner can hand the project to someone else under Transfer ownership. The new owner takes full control; the previous owner stays on as an editor rather than being locked out.

Portfolios

Portfolios are simpler. A portfolio is private to its owner by default, or shared with named people as read-only viewers (Configuration → Sharing). There is no "everyone" option and no editor level. Only the owner can delete the portfolio, add or remove its projects, and edit its description.

Site-wide setup

Cost accounts, attributes and the role library are not tied to one project. Everyone can see them; only Jira site administrators can create, edit or delete them.

Locked out?

If a restricted project's owner has left, a Jira site administrator can still open it. The app shows a notice that they are seeing it as a site admin, and they can repair its Sharing so it never ends up with nobody able to manage it.
