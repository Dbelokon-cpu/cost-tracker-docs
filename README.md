Public documentation, privacy policy and security policy for the [Cost Tracker](https://github.com/Dbelokon-cpu/cost-tracker) Jira app by Vudia. The app's source code lives in a separate, private repository — this one holds only the user-facing docs.

Live at:
- https://dbelokon-cpu.github.io/cost-tracker-docs/
- https://dbelokon-cpu.github.io/cost-tracker-docs/privacy.html
- https://dbelokon-cpu.github.io/cost-tracker-docs/security.html

This is a static site with no build step — three self-contained HTML files, served via GitHub Pages.
